# Changelog

## 7.0.0 (JARVIS)
- Реални фајл операции со верификација и корпа (create/read/write/edit/copy/move/delete/search).
- Windows + WSL контрола: PowerShell, CMD, bash, WSL, процеси, апликации, clipboard, екран, тон, говор, нотификации.
- Facebook и YouTube преку твојот Chrome без API и без зачувани лозинки/cookies, со верификација на резултатот.
- Вид без клуч: DOM + геометрија + OCR.
- Нов NL рутер (mk/en) + планирање во чекори; непознато = blocked, никогаш лажен успех.
- Слој за верификација и потврди за деструктивни/профилни акции.
- Распоред со retry/backoff; синхронизација каталог/статус/интенти.
