# Legacy files

Оваа папка ги содржи старите flat HUGO v7 модули и локални state/data snapshots што беа зачувани во root во претходна структура.

Тие не се активниот runtime и не ги користи `package.json`.

Активниот проект е организиран вака:

- `scripts/` - runtime source, CLI, UI, browser, memory и tests
- `data/` - каталози и конфигурациски data
- `memory/` - активна локална memory состојба
- `docs/` - документација
- `archives/` - стари bundle архиви
