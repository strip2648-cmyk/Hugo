# Енваронмент (сите опционални)

| Променлива | Ефект |
|---|---|
| `HUGO_LOCAL_AI_ENDPOINT` | опционален локален модел |
| `HUGO_CHROME_PORT` | порта на браузерот (9222) |
| `HUGO_CHROME_BIN` | пат до Chrome/Chromium |
| `HUGO_CHROME_PROFILE` | профил на HUGO (копија од твојот) |
| `HUGO_DEVICE_TOKEN` | го штити UI и gateway |
| `HUGO_UI_PORT` / `HUGO_GATEWAY_PORT` | 8765 / 8787 |
| `HUGO_REPO` / `HUGO_BRANCH` | git репо за memory sync |
| `HUGO_MEMORY_AUTO_PUSH` | дали меморијата се push-ира |
| `HUGO_RETENTION_DAYS` | чување разговори (90) |
| `HUGO_TZ` | временска зона |
| `HUGO_VOICE_LANG` | јазик за говор |
| `HUGO_LOG_LEVEL` | error / warn / info / debug |
